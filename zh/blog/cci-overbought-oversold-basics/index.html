CCI商品通道指数：是什么、如何计算、如何解读超买超卖

快速回答

CCI（商品通道指数）是一种震荡指标，用于衡量价格偏离其近期均值（通常为20周期）的程度。高于+100表示超买；低于−100表示超卖。由于它没有固定的上下限，极高或极低的数值显示的是异常的波动，但并不是自动的反转信号：在强势趋势中，价格可能会继续走下去。

CCI，即Commodity Channel Index（商品通道指数）的英文缩写，由唐纳德·兰伯特（Donald Lambert）在1980年提出。尽管名字里有“商品”，它实际上适用于任何有价格图表的资产：股票、指数、货币和加密货币。本文使用黄金期货合约（GC=F，以美元/金衡盎司计价，数据来自雅虎财经）2026年4月至10月间的真实每日报价来进行计算，并展示该指标实际显示出的情况。

CCI与RSI和随机指标的区别在于它没有上限也没有下限。当价格出现非常异常的波动时，CCI也会随之走到很远的数值，这正是它用来衡量波动强度的有用之处。

什么是CCI

CCI衡量当前周期的典型价格偏离其近期均值的程度，以最近若干周期的平均偏差作为标尺。正值意味着价格高于均值；负值意味着价格低于均值。数值的绝对值越大，这种偏离就越异常。

最常用的周期是20。兰伯特选择了常数0.015，使大部分读数落在−100到+100之间。因此这两条线成为了超买（高于+100）和超卖（低于−100）的参考线。

如何计算CCI

共分四步：

  • 典型价格（TP）：（最高价 + 最低价 + 收盘价）÷ 3，针对最近20个周期中的每一个计算。
  • 典型价格均值：这20个典型价格的简单平均值。
  • 平均偏差：每个典型价格与均值之间距离的绝对值的平均数。
  • CCI = （当前典型价格 − 典型价格均值） ÷ （0.015 × 平均偏差）。

使用黄金真实数据的例子

2026年8月6日黄金期货最高价为4,363.70美元，最低价为4,281.20美元，收盘价为4,299.60美元。当天的计算如下：

  • 8月6日的典型价格 = (4,363.70 + 4,281.20 + 4,299.60) ÷ 3 = 4,314.83
  • 7月10日至8月6日这20个典型价格的平均值 = 4,090.77
  • 这20个数值相对均值的平均偏差 = 53.88
  • CCI = (4,314.83 − 4,090.77) ÷ (0.015 × 53.88) = 224.06 ÷ 0.8082 ≈ 277

这是整个图表区间内20周期CCI出现的最高读数。原因是在两个交易日（8月5日和6日）内，典型价格从约4,138美元跳升至超过4,314美元，而在此之前，价格已经在4,000至4,100美元附近波动了近一个月。由于平均偏差很小，比均值高出224美元的跳升就造成了极高的CCI值。

真实案例：2026年黄金的CCI

在2026年4月1日至10月7日期间，黄金从4,813.10美元跌至4,140.70美元，跌幅13.97%。在这段时间里，CCI八次跌破−100，四次突破+100。三个时刻很好地展示了该指标能做什么、不能做什么。

6月：极端超卖并未标示底部

6月10日CCI达到−260.81，是该期间的最低读数，当时黄金收于4,133.30美元。随后出现了一次快速反弹：6月15日价格达到4,351.60美元（上涨5.3%），CCI回升至−54.8。但下跌并未就此结束。黄金于6月24日收于4,008.80美元，并于6月30日创下该区间的最低价3,955.40美元。强烈的超卖信号显示的是短期内跌幅过大，而不是趋势的终结。

8月：上涨初期的超买

CCI于8月4日突破+100，当时价格为4,152.60美元，并在8月6日达到277。如果因为看到超买就卖出，就会过早离场：在8月4日之后的十个交易日，黄金涨到了4,420.60美元（涨幅6.45%），而这段行情中的最高收盘价出现在8月24日，为4,697.80美元，比8月6日的收盘价高9.3%。在趋势刚开始的阶段，高CCI显示的是强势，而不是衰竭。

9月：顺应趋势的超卖

9月14日CCI再次跌破−100（−117.78），当时价格为4,351.90美元。十个交易日后，黄金跌至4,168.40美元，跌幅4.22%，10月7日收于4,140.70美元，CCI仍在−115.09。在这个例子中，超卖信号与走势方向一致：把−100当作买入信号的人，正好与下跌趋势对着做。

如何使用CCI

CCI高于+100

说明价格明显高于近期均值，力度超出该资产的正常水平。在横盘市场中，这通常预示着价格将回落到正常区间。而在趋势刚开始时，比如8月的例子，这恰恰可能是行情正在增强的信号。应把它当作警示，而不是卖出指令。

CCI低于−100

情况正好相反：价格下跌幅度超过了正常水平。在下跌趋势中，该指标可能多次跌破−100，就像黄金在5月到7月期间那样。读数非常负面时通常会伴随短暂的反弹，但并不能说明下跌何时结束。

回归区间内

许多交易者会等待CCI离开极端区域、重新回到−100至+100的区间内，才考虑进行逆势交易。这种回归表明动能已经减弱，这比仅仅进入极端区域本身更有参考价值。不过，仍然值得在价格上寻找确认信号：附近的支撑或阻力、某种K线形态，或一次短暂的突破。

零线穿越

另一种常见的解读是，把CCI在零以上视为价格高于20周期均值，零以下则视为价格低于均值。这是在观察极端区域之前，用来过滤主导方向的一种简单方法。

局限性

CCI只使用过去的价格，因此在剧烈变化时存在滞后，也完全不考虑新闻因素。由于它没有上下限，并不存在某个代表走势结束的具体数值：8月的277并没有阻止后续再上涨9%。而周期的选择会大大改变指标的表现：使用14周期时指标会更敏感，产生更多信号；使用30周期时则会更迟缓。

使用CCI时的常见错误

  • 一旦CCI超过+100就自动卖出，或跌破−100就自动买入，而不看趋势。
  • 认为非常极端的CCI读数，比如−260，就能保证立即反转。
  • 单独使用该指标，而不结合支撑、阻力或市场背景。
  • 不经测试就更改周期，并把不同周期的读数当作可以直接比较的数值。
  • 忘记上面的例子描述的是已经发生的事，不是将要发生的事。
