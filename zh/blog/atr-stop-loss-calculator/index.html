用ATR计算止损：如何确定距离

Duotide 团队 · 2026/09/24 · 阅读 4 分钟

刚开始交易的人最常见的疑问之一，就是止损应该设在多远的位置。设得太近，会增加因资产正常波动而被止损出局的可能性；设得太远，则会在交易判断错误时增加损失。一个实用的解决方法，是用ATR（Average True Range，平均真实波幅）作为近期波动率的参考，来计算止损的距离。

ATR衡量的是什么

ATR衡量的是在特定数量的周期内（通常是14个）价格变动的平均幅度。它不显示方向，只显示该资产通常的波动程度。对于每一根K线，都会计算真实波幅（True Range），取以下三个选项中的最大值：当前K线最高价与最低价之差、当前最高价与前一根收盘价之差，以及当前最低价与前一根收盘价之差。ATR就是这些数值在所选周期内的平均值。

基于ATR的止损公式

止损距离 = ATR × 乘数

对于多头交易：止损 = 入场价格 - 止损距离

对于空头交易：止损 = 入场价格 + 止损距离

一个用雷亚尔计算的示例

假设在一只报价50.00雷亚尔的股票上做多，日ATR为1.20雷亚尔，乘数为2。止损距离为：

  • 距离 = 1.20雷亚尔 × 2 = 2.40雷亚尔
  • 止损 = 50.00雷亚尔 - 2.40雷亚尔 = 47.60雷亚尔

现在假设账户资金为20000.00雷亚尔，每笔交易的最大风险为1%，即200.00雷亚尔。仓位大小的计算方式是用以雷亚尔计的风险除以止损距离：

  • 仓位大小 = 200.00雷亚尔 / 2.40雷亚尔 ≈ 83股

有了这个仓位，如果价格跌到47.60雷亚尔，在扣除佣金成本之前，损失将接近计划中的200.00雷亚尔。一个2R的参考目标，也就是所承担风险的两倍，大约会在54.80雷亚尔附近，但这只是一个数学上的参考，并不保证价格真的会到达那里。

ATR不能取代图表结构

ATR回答的问题是这个资产通常会移动多少。它无法回答我的入场想法在哪里会被判定为错误这个问题。第二个问题的答案来自图表分析，比如之前的低点或一个支撑区域。建议的顺序是：首先标出会使这笔交易失效的价位，然后测量入场点与该价位之间的距离，最后再把这个距离与ATR进行比较，看它相对于近期波动率是否合理。如果结构上的距离远小于ATR所暗示的水平，止损可能对该资产的正常噪音来说设得太紧了。

不存在完美的乘数

较低的乘数会产生更近的止损，在相同的雷亚尔风险下对应更大的仓位，但也更容易受到常见波动的影响。较高的乘数会产生更远的止损和更小的仓位，减少因噪音而被止损出局的情况，但也需要价格走得更远，才能达到同样倍数的风险回报。理想的乘数取决于资产、所操作的时间周期和交易设置的类型，在为所有交易采用一个固定数值之前，值得先在历史数据中测试不同的数值。

注意跳空和执行问题

这个计算假设仓位会恰好在止损价位平仓。但在实践中，跳空、消息面和流动性不足的市场，可能导致实际成交价格与计划价格相差很远，尤其是在隔夜或周末休市的资产上。ATR有助于在正常条件下估算预期风险，但并不能消除市场承压时刻执行结果比计划更差的风险。

操作前的最后提醒

应该先确定乘数，再看由此得出的仓位大小，而不是反过来。仅仅为了得到一个看起来舒适的仓位大小而去选择乘数，颠倒了风险管理的逻辑：应该是止损来决定仓位大小，而不是想要的仓位大小来决定止损。
