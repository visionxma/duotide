什么是MACD，如何在实践中使用这个指标

Duotide 团队 · 2026/09/24 · 阅读 4 分钟

MACD，即Moving Average Convergence Divergence（指数平滑异同移动平均线）的缩写，是一个基于指数移动平均线构建的趋势和动量指标。它有助于直观地看出短期行情相对于稍长期行情，力量是在增强还是在减弱。

MACD是如何计算的

该指标由三部分组成。MACD线是两条指数移动平均线之间的差值，通常为12周期和26周期：

MACD线 = EMA(12) − EMA(26)

信号线是在MACD线本身基础上计算出的9周期指数移动平均线：

信号线 = MACD线的EMA(9)

柱状图显示的是这两条线之间的差值：

柱状图 = MACD线 − 信号线

一个简化的数值示例

假设在某一时刻，某股票12周期的指数移动平均线为R$ 25,40，26周期的指数移动平均线为R$ 24,80。MACD线为：

MACD线 = R$ 25,40 − R$ 24,80 = 0,60

如果根据MACD线本身近期数值计算出的信号线为0,45，那么柱状图为：

柱状图 = 0,60 − 0,45 = 0,15

像这个例子中这样，一个为正且不断增大的柱状图，表明MACD线正在向上远离信号线，这通常被解读为短期上涨动能的增强。

两条线之间的交叉

当MACD线向上穿越信号线时，通常被解读为短期买方力量可能增强的信号。当它向下穿越时，解读通常相反。这些交叉在与图表更大的趋势方向一致时往往更可靠，而在市场横盘运行时则不太可靠，因为在这种情况下MACD可能连续产生多次假交叉。

零轴的穿越

除了两条线之间的交叉之外，还值得关注MACD线本身何时穿越零轴上方或下方。这种情况发生在12周期均线超过26周期均线，或反过来的时候，标志着这两条均线关系发生了更广泛的变化，通常与一个比MACD线和信号线简单交叉更长一些的中期趋势变化相关联。

MACD的背离

与RSI一样，MACD也可能与价格形成背离。如果价格创出新高，但MACD的柱状图却形成了比前一个更低的峰值，这表明上涨行情正在失去力量，即使价格尚未反转。底背离的情况则相反。背离是对行情力度的一种警示信号，而不是对反转确切时间的精确预测。

使用MACD操作时常见的错误

  • 仅仅因为出现交叉就进行每一笔操作，而不考虑更大周期图表的趋势。
  • 忽视MACD是一个基于移动平均线构建的滞后指标，这意味着它是在部分行情已经发生之后才确认的。
  • 只使用MACD，而不结合支撑、阻力或成交量的解读。
  • 在没有事先测试的情况下，就改变12、26、9这组默认参数，而不验证这种改动是否真的能改善所操作资产和时间周期上的结果。

趋势市场与横盘市场中的MACD

MACD通常在已经处于明确趋势的市场中给出最好的信号，因为在这种情境下，交叉往往能跟随更持久的行情。在没有明确方向、横向运行的市场中，构成该指标的两条均线会频繁相互交叉，产生一连串迅速相互抵消的信号，如果有人试图把每一次交叉都当作一轮新趋势的开始去操作，就可能因此亏损。因此，在信任一个MACD信号之前，值得确认更大周期的图表是否真的显示出一轮正在进行的趋势，还是该资产只是在一个区间内波动。

如何把MACD融入更完整的分析

MACD最适合在已经考虑了更大趋势和重要价格水平的分析中，作为动量的确认工具，而不是作为唯一的入场触发条件。在真实操作中信任它之前，先在该特定资产的历史数据上测试这个指标的表现，有助于理解它通常在什么市场条件下效果更好、在什么条件下更容易产生假信号。
