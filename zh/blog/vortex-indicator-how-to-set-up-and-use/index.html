涡旋指标：如何设置与使用

返回顶部

涡旋指标（Vortex）的诞生灵感在技术分析工具中相当罕见：它的创造者Etienne Botes和Douglas Siepman，借鉴了奥地利发明家Viktor Schauberger关于水流的观察，提出金融市场的走势可能与自然界中观察到的涡旋模式相似。实际上，最终得到的是一个由两条线组成的趋势指标，其解读方式比这个类比听起来要简单得多。

计算背后的思路

涡旋指标衡量的是当前K线最低价与前一根K线最高价之间的距离（上涨动向），以及当前K线最高价与前一根K线最低价之间的距离（下跌动向）。这两个距离中的一个相对于另一个越大，对应方向的行情就越强。这两个数值经过一段周期（默认14）的平滑处理后，形成该指标的两条线：VI+（上涨动向）和VI-（下跌动向）。

计算中还考虑了每根K线的真实波幅——与ATR和ADX使用的是同一概念——这有助于该指标即使在K线之间出现跳空时也能捕捉到行情。

如何设置

涡旋指标属于动量指标（或趋势指标，视平台而定）类别，默认对两条主线都使用14周期。超买和超卖水平通常分别设置为1.1和0.9，不过这两个水平在该指标的解读中所占的比重，低于VI+和VI-两条线之间的交叉。

如何解读信号

  • 上涨信号：VI+线原本低于VI-线，向上穿越并保持在其上方——表明上涨动向已占据主导。
  • 下跌信号：VI-线原本低于VI+线，向上穿越并保持在其上方——表明下跌动向已占据主导。
  • 两线之间的距离：交叉之后VI+和VI-之间的间距越大，当前趋势就被认为越强。

举个例子：在某货币对中，VI-线已在VI+线上方持续数周（下降趋势），随后VI+线向上穿越VI-线，并且在接下来的K线中两线之间的距离开始扩大。这种组合——交叉加上距离扩大——被解读为趋势方向确实已经改变的确认，而不只是可能在下一根K线就反转的孤立交叉。

并非每次交叉都该变成一次入场

VI+和VI-之间的交叉不应被当作自动的买入或卖出指令，而应视为提醒你更仔细关注该资产的信号：检查价格近期的表现，评估附近是否存在重要的支撑或阻力，然后才考虑按指示方向入场。在没有明确趋势的市场中，交叉往往会在短时间内反复出现，却没有产生可以把握的行情——这与几乎所有趋势指标在横盘市场中都会出现的假信号问题相同。

将涡旋指标与其他指标结合使用

由于涡旋指标只衡量趋势，把它与性质不同的指标结合使用，比与另一个本质上衡量同样内容的趋势指标结合更有帮助。MACD和ADX通常被认为是不错的搭配：MACD强化了动量的判断，而ADX有助于确认涡旋交叉所显示的趋势力度，是否真的足够强劲，值得作为入场的理由。

风险管理依然不可或缺

与任何趋势指标一样，涡旋指标并不总是准确，基于它构建的策略应当在入场前就设定止损，并在合适的情况下设定明确的止盈目标。无论背后的逻辑多么精巧，没有任何工具能一直给出正确的信号——以其他方式对待涡旋指标，就是无视任何趋势策略在大量操作中真实的表现方式。

在把该指标用于真实操作之前，还值得在不同资产和周期上进行测试：在股票日线图上表现良好的14周期设置，由于两个市场在波动性和行为上的差异，未必能在某个货币对的日内图上产生同样的结果。
