什么是RSI相对强弱指数，如何计算

RSI，即相对强弱指数，是技术分析中最常用的动量指标之一。它比较某资产近期涨幅的力度和近期跌幅的力度，生成一个0到100之间的数字，帮助识别一次行情是否可能已经拉伸过度。

RSI的公式

计算首先要得到特定周期数（通常为14）内的平均涨幅和平均跌幅。基于这两个平均值，计算出相对强度，称为RS：

RS = 平均涨幅 / 平均跌幅

然后，用以下公式把RS转换成0到100的刻度：

RSI = 100 − [100 / (1 + RS)]

一个手工演算的例子

为了简化计算，这里用一个只有5次价格变动的例子，而不是通常使用的14次，仅用来说明计算过程。假设某股票连续几天的收盘价为：R$ 10,00；R$ 10,20；R$ 10,15；R$ 10,40；R$ 10,30；R$ 10,50。

相邻两次收盘价之间的变化为：

  • 第2天：+R$ 0,20（上涨）
  • 第3天：−R$ 0,05（下跌）
  • 第4天：+R$ 0,25（上涨）
  • 第5天：−R$ 0,10（下跌）
  • 第6天：+R$ 0,20（上涨）

把三次上涨相加再除以5次变动，得到平均涨幅为(0,20 + 0,25 + 0,20) / 5 = 0,13。把两次下跌相加再除以5次变动，得到平均跌幅为(0,05 + 0,10) / 5 = 0,03。相对强度为RS = 0,13 / 0,03 = 4,33。代入最终公式：RSI = 100 − [100 / (1 + 4,33)] = 100 − 18,76 = 81,24。

接近81的RSI表明，在这个简化的周期内，近期的涨幅明显压倒了跌幅，使该指标处于超买的读数。

如何解读超买和超卖水平

传统的解读认为，高于70的数值为超买，暗示上涨行情可能已经拉伸过度；低于30的数值为超卖，对下跌行情暗示同样的情况。这些数字并不是自动的买入或卖出信号。在强劲的上升趋势中，RSI可能长时间保持在70以上，如果每次它穿越这个水平就卖出，可能意味着提前退出一个仍有很大延续空间的趋势。

背离：当价格和RSI出现分歧

当价格创出新高，但RSI的高点却低于前一个高点时，就出现了背离，这表明即使价格仍在上涨，上涨行情的内在力量也正在减弱。反过来也是如此，价格创出更低的低点，而RSI却形成更高的低点。背离是对行情可能正在失去力量的一种警示，而不是对即将反转的保证。

使用RSI时常见的错误

  • 把每一次穿越70或30的情况都当作自动的入场信号，而忽视更大趋势的背景。
  • 单独使用RSI，而不检查支撑、阻力或图表的整体结构。
  • 把不同资产的RSI放在一起比较，仿佛同一个数字在任何波动性背景下都代表同样的意思。
  • 忽视时间周期：在5分钟图上计算出的RSI，衡量的内容与日线图上同一指标衡量的内容大不相同。

不同时间周期上的RSI

根据所使用的图表不同，同一资产可能显示出完全不同的RSI读数。基于5分钟K线计算的RSI，会对极短期的波动做出反应，在一天之内可能多次在超买和超卖之间切换。而基于日K线或周K线计算的RSI，则往往变化更缓慢，通常反映的是更长周期的行情。在用一个固定规则来比较RSI读数之前，值得先确认所选的时间周期，是否与计划进行的操作类型相符，无论是一次快速的日内交易，还是一个持续多天的仓位。

如何更负责任地使用RSI

RSI最适合作为更全面分析中的一部分，而不是一个单独的入场触发条件。把RSI的解读与更大时间周期的趋势、支撑和阻力水平，以及价格在这些水平附近的反应结合起来，通常比仅仅依据某个固定数字的穿越，能得到更可靠的判断。与任何技术指标一样，RSI描述的是价格过去的表现，并不能保证接下来会发生什么。
