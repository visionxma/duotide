快速回答

甲骨文（ORCL）的股价受人工智能云合同驱动，这些合同使在手订单达到约5530亿美元，而建设数据中心以履行这些合同的成本，则使自由现金流转为负值。2026年，该股在6月一度涨至248.15美元，之后一个月内下跌40.9%，并于10月7日收盘报年内下跌26.3%。

几十年来，甲骨文一直以数据库和企业软件闻名，但到2026年，市场开始把它作为人工智能基础设施的核心一环来交易。数十亿美元规模的云合同，与同一份财报中沉重的数据中心支出和负的自由现金流并存。这种反差有助于解释该股票为何在这一年波动如此剧烈。

本文整理了关于甲骨文（代码ORCL，纽约证券交易所上市）在2026年年中公布的数据，并用带布林带指标的真实日线图，展示3月至10月发生的情况。文中的业务数据反映的是当时的情况。本文不构成买入或卖出建议。

甲骨文做什么

甲骨文向政府、银行、医疗网络、运营商和大型企业销售数据库、企业应用和云基础设施。公司的大部分营收来自长期订阅，这比一次性许可证销售提供了更高的可预见性。

公司近期的重心是Oracle Cloud Infrastructure（OCI），提供计算、存储和网络服务，其中包括用于训练和运行人工智能模型的服务。在这个市场上，公司与Amazon Web Services、Microsoft Azure和Google Cloud竞争，依靠的是一批已经使用其数据库多年的客户群体。

2026年公布的数据

  • 2026财年第三季度，剩余履约义务（RPO）估计为5530亿美元，同比增长约325%，其中包括与OpenAI、Meta和xAI签订的大型合同。
  • 年度营收约为574亿美元，同比增长8.4%。
  • 自由现金流为负，约3.94亿美元，原因是每年在数据中心上投入数百亿美元的支出。
  • 截至6月的过去12个月，每股收益（EPS）为5.57美元。

两组有助于理解该股票的计算

  • 按年度营收计算的在手订单：5530亿美元 ÷ 574亿美元 = 相当于约9.6年的年度营收。合同已经存在；挑战在于建设足够的产能来履行它。
  • 用真实价格计算的市盈率：以6月1日全年最高收盘价248.15美元计算，市盈率为248.15 ÷ 5.57 = 44.6倍。以7月24日全年最低收盘价114.99美元计算，则降至20.6倍。同样的利润，不到两个月内估值倍数就减半。

真实案例：2026年甲骨文与布林带

该图表展示了ORCL的日线K线图（数据来自雅虎财经），以及20日、2个标准差的布林带。该股2025年收于194.91美元，到2026年10月7日报143.56美元，年内下跌26.3%。布林带有助于观察每个阶段波动性的变化。

4月：收盘高于上轨并非顶部信号

4月13日，该股单日上涨12.7%，从138.09美元涨至155.62美元。在接下来的四个交易日（4月14日至17日），收盘价均高于上轨。如果因为“涨得太多”而卖出，就会错过后续行情：6月1日，ORCL收于248.15美元，比4月10日的收盘价高出79.7%。在强势趋势中，股价可能会紧贴上轨运行。

6月：布林带张到最大，随后下跌40%

5月29日至6月2日期间，该股在经历两个交易日分别上涨10.8%和9.9%之后，再次连续三天收盘高于上轨。随后的反转非常剧烈：6月30日收于146.55美元，比6月1日的高点低40.9%。前一天，即6月29日，布林带的宽度达到均线的62.9%，为本期最大值。即便在下跌过程中，股价也没有收于下轨之下，因为此前的上涨本身已经拉宽了布林带。

8月至9月：布林带收窄，突破随后失败

8月28日，20日均线为146.98美元，上轨为155.03美元。标准差为（155.03 − 146.98）÷ 2 = 4.03，下轨为146.98 − 2 × 4.03 = 138.93美元。布林带宽度降至均线的11%，接近本期最低值：这是收窄，预示着波动性偏低。9月4日和8日，该股收盘高于上轨，最高达到162.52美元。但这次突破没能持续：9月28日收于132.60美元，低18.4%，几乎贴着下轨。

如何分析甲骨文的股票

在手订单与产能

每个季度都要关注RPO是否持续增长，尤其是云业务营收是否在加速。相当于近十年营收的在手订单，只有在数据中心按时建成的情况下才能转化为利润。

现金与债务

由于自由现金流为负，扩张只能依赖融资。债务的走势及其成本，和合同规模同样重要。

客户集中度

大部分在手订单来自少数几家大型人工智能客户。其中任何一家的计划变化，都会对股价产生影响。

局限性

布林带衡量的是波动性，而不是方向：股价高于上轨可能代表强势，也可能代表过度，只有结合背景才能区分。上面的市盈率使用的是6月的利润数据，而在手订单和现金数据每个季度都会变化。

分析甲骨文股票时常见的错误

  • 把在手订单和已确保的营收混为一谈：签订的合同仍取决于能否交付，以及客户是否履约。
  • 忽视负的自由现金流，以及用于为扩张融资的债务。
  • 因为股价收盘高于上轨就自动卖出，就像4月那样。
  • 在布林带收窄之后，不等待确认就买入每一次突破，就像9月那样。
  • 只看某一天的市盈率，而这只股票全年的收盘价在114.99美元到248.15美元之间波动。
  • 把2026年的图表当作预测：它展示的是已经发生的事，不是未来会发生的事。
