甲骨文（ORCL）2026年股票：是什么在推动股价

几十年来，甲骨文一直以数据库和企业软件闻名，但到2026年，这家公司越来越多地被市场视为人工智能基础设施的核心一环。价值数十亿美元的云合同，与同一份财报中沉重的数据中心支出和不断增长的债务并存——这种反差有助于解释为什么这只股票会吸引投资者和交易者如此多的关注。

本文整理了关于甲骨文（在纽交所上市，代码ORCL）被提及的主要数据和因素，数据截至2026年6月，按当时公开披露的情况呈现。这些数值会随时间变化，本文任何内容都不应被解读为买入或卖出建议——目的是梳理当时推动股价的因素，帮助理解哪类因素值得持续关注。

甲骨文做什么、营收从何而来

甲骨文向大型机构——政府、银行、医疗网络、电信运营商以及财富500强企业——销售数据库、企业应用和云基础设施。公司大部分营收来自长期订阅，这让它比传统的单次软件许可模式拥有更可预测的现金流。

近年来，公司的重心转向云计算，尤其是Oracle Cloud Infrastructure（OCI）平台，提供计算能力、存储和网络服务——其中包括专门用于训练和运行人工智能模型的服务。在这个市场上，甲骨文与Amazon Web Services、Microsoft Azure和Google Cloud等公司竞争，但依靠一个特定优势：已经使用其数据库和应用多年的客户群，可以逐步将这些工作负载迁移到甲骨文自己的云平台上。

2026年6月市场关注的数据

根据雅虎财经2026年6月的数据，甲骨文市值为6624亿美元，股价报230.33美元，年内累计涨幅为18.4%。市盈率（P/E）为41.4倍，按预期业绩（forward P/E）计算降至28.6倍——这一差异表明市场已经为随后几期相当可观的利润增长定价。52周区间为134.57美元至345.72美元，派发的股息收益率为每年0.9%，每股收益（EPS）为5.57美元。

增长引擎：人工智能云合同

被提及最多用来解释市场对该股兴趣的因素，是市场对Oracle Cloud Infrastructure用于人工智能工作负载的需求。公司已与OpenAI、Meta和xAI等知名企业签订了长期大额合同，这帮助公司在2026财年第三季度积累了估计高达5530亿美元的剩余履约义务（RPO）——较上一年增长约325%。这个数字是未来几年合同营收的一个指标，任何显示它继续增长，或有新的人工智能和云合同正在签订的信号，往往都会受到市场的密切关注。

硬币的另一面：支出与现金流为负

为满足这一合同量而建设产能需要巨额投资。甲骨文一直每年花费数百亿美元建设面向人工智能的新数据中心，这导致公司自由现金流转为负值，约为负3.94亿美元，尽管其软件业务历来盈利丰厚。公司约574亿美元的年度营收同比增长8.4%——这个速度虽然稳健，但远慢于云合同在手订单本身的增长速度。

这正是围绕该股票争论的核心：如果市场逐渐相信这些巨额投资会在未来几年产生相应回报，股价的上涨往往能够持续甚至扩大；如果现金消耗持续处于高位，且市场对偿还与这一扩张相关债务的能力产生怀疑，股价则往往承压。

需要持续关注的因素

当时分析师根据可得数据通常会持续关注的因素包括：云合同在手订单的季度变化、数据中心产能相对于真实需求的扩张速度、营收在少数大型人工智能客户中的集中程度，以及为支持这一扩张而借入债务的走势。

值得强调的是，本文呈现的数据反映的是2026年6月——原始报道发布时——的情况，此后可能已发生重大变化。本文仅供教育参考：不构成买入、卖出或持有该股票的建议，任何投资决定都应考虑最新数据、每位投资者自身的风险状况，以及在股票市场操作始终存在的本金亏损可能性。
