快速回答

最适合新手的五种期权策略是买入看涨期权、买入看跌期权、备兑卖出、保护性看跌期权和跨式组合。其中只涉及买入期权的三种，最大亏损就是支付的权利金。所有策略中，除了要判断对价格方向，还必须判断对到期的时间。

期权吸引新手，是因为花小钱就能参与一次大行情。很少有人提到的是，损失100%的权利金是很常见的结果，而且判断对方向还不够：还必须判断对时间。下面五种结构，从最简单到最需要专注力依次排列。

为了让这些计算有真实依据，我们使用苹果公司（AAPL，Yahoo Finance）2026年5月至10月的真实日线收盘价。示例中的期权权利金是假设数值，只是为了计算而选取；真实的期权价格取决于当天的波动率、到期时间和利率。

什么是期权

期权是一种赋予权利的合约。买入看涨期权（call）的人，有权在到期前以约定价格（行使价）买入标的资产。买入看跌期权（put）的人，有权以行使价卖出。为了获得这项权利，买方要向卖方支付权利金。每份合约通常对应100股。

如何计算期权到期时的结果

  • 看涨期权：到期价值 = 股价 − 行使价，若为正；否则为零。
  • 看跌期权：到期价值 = 行使价 − 股价，若为正；否则为零。
  • 买方的结果 = 到期价值 − 已支付的权利金。最大亏损就是权利金。

真实案例：2026年5月至10月的苹果公司

AAPL在2026年5月1日收于280.14美元，10月7日收于336.67美元，涨幅20.2%。途中曾在6月25日跌至最低273.75美元，又在9月22日涨到最高345.34美元。这是一个很好的场景，可以展示同一只股票在不同时点如何奖励或惩罚每种策略。下面所有案例都把结束日期当作到期日来处理。

5种期权策略

1. 买入看涨期权：上涨行情，亏损有限

5月1日，股价为280.14美元，假设买入一份行使价290美元的看涨期权，权利金为假设的5.00美元（每份合约500美元）。6月1日，AAPL收于306.31美元。该看涨期权价值为306.31 − 290 = 16.31美元，利润为16.31 − 5.00 = 每股11.31美元，即每份合约1,131美元，相当于权利金的226%。如果股价低于290美元，亏损就是全部500美元，不会更多。

2. 买入看跌期权：保护或押注下跌

6月8日，股价为301.54美元，假设买入一份行使价295美元的看跌期权，权利金5.00美元。6月25日，AAPL收于275.15美元，该看跌期权价值为295 − 275.15 = 19.85美元。但如果到期日是买入一个月后的7月8日，那时股价已经回到313.39美元，高于行使价，看跌期权会归零到期：损失100%的权利金。方向在两周内判断正确；时间却没判断对。

3. 备兑卖出：对已持有股票收取收入

持有100股、成本价313.39美元（7月8日买入）的人，卖出一份行使价330美元的看涨期权，收取权利金4.00美元。8月5日，股价收于311.00美元，低于行使价。该看涨期权归零到期，卖方保留4.00美元，结果为−2.39 + 4.00 = 每股1.61美元。代价体现在上涨行情中：7月29日，AAPL收于338.19美元。如果以那天为到期日，收益会被锁定在330 − 313.39 + 4.00 = 每股20.61美元，而只持有股票的人则能拿到24.80美元。

4. 保护性看跌期权：一份价格确定的保险

7月29日以338.19美元买入股票的人，买入一份行使价325美元的看跌期权，权利金6.00美元。8月26日，AAPL收于313.45美元：如果没有保护，亏损会是每股24.74美元（7.3%）。有了这份看跌期权，无论股价跌多少，最大亏损都被锁定在338.19 − 325 + 6.00 = 19.19美元。如果股价上涨，这份看跌期权会贬值，那6.00美元就相当于保险的成本。

5. 跨式组合：押注行情的幅度

6月15日，股价为296.42美元，假设买入一份行使价295美元的看涨期权和一份同样行使价的看跌期权，各7.00美元（合计14.00美元）。只有当到期时股价涨过309美元或跌破281美元，这个跨式组合才会盈利。7月15日，AAPL收于327.50美元：看涨期权价值32.50美元，看跌期权为零，利润为32.50 − 14.00 = 每股18.50美元。如果股价一直停在295美元附近，两端权利金几乎会全部损失。

如何使用这些期权策略

从已知的最大亏损开始

买入看涨期权、买入看跌期权和保护性看跌期权的风险都被限制在支付的权利金之内。只要权利金只占资金中很小的一部分，这些是最适合新手的策略。

备兑卖出要求持有股票

备兑卖出之所以“有保护”，是因为你持有这些股票。没有持有标的资产就卖出看涨期权是另一种策略，理论上风险无限，不适合新手。

时间对买方不利

即使股价不动，期权也会随着到期日临近而贬值。这正是看跌期权那个案例失败的原因：行情确实出现了，但在到期之前就结束了。

局限性

这些案例使用的是到期时的结果和假设的权利金。实际操作中，市场预期波动率上升时权利金会上涨，很多期权系列的流动性很低，买卖价差可能很大。这些案例描述的是AAPL在该期间实际发生的情况，不是对未来的预测。

期权交易中的常见错误

  • 只因为便宜就买入深度价外的期权：它们归零的概率更高。
  • 为预期的行情选择过短的到期时间。
  • 因为最大亏损已知，就把资金中很大一部分押在权利金上。
  • 在没有持有标的资产或足够保证金覆盖最坏情况的情况下卖出期权。
  • 忽视某个系列的流动性，导致无法按预期价格平仓。
  • 在事件之前搭建跨式组合，却不知道权利金已经把预期的行情幅度计算在内。

在用真实资金交易之前，可以在模拟账户或表格里用当天真实的权利金搭建这些结构，并跟踪到到期日。记录你的预期和实际发生的情况：这是理解时间和波动率如何影响结果的最低成本方式。
