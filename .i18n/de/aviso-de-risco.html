Risikohinweis

Sie können das gesamte investierte Kapital verlieren. Investieren Sie kein Geld, das Sie zum Leben brauchen, und keine Mittel aus Notreserve, Miete, Schulden oder Finanzierungen.

Marktrisiko

Gehebelte Produkte und Derivate verstärken Gewinne und Verluste. Eine kleine Preisschwankung des Basiswerts kann die Position auf null setzen. Dieses Risiko liegt im Produkt: Es besteht auch dann, wenn die Plattform einwandfrei funktioniert, und es gibt keine Sicherheitseinstellung, die es beseitigt.

Kontrahentenrisiko

Duotide ist nicht von der CVM zugelassen und gibt eine Registrierung in St. Vincent und die Grenadinen (SVG) an. Das bedeutet, dass es keinen anwendbaren Garantiefonds und keine brasilianische Aufsichtsbehörde gibt, die im Falle einer Störung, Kontosperrung oder Nichtauszahlung angerufen werden könnte. Das Risiko, dass die Gegenpartei nicht zahlt, tragen Sie vollständig selbst.

Risiko vergangener Wertentwicklung

Vergangene Ergebnisse sagen nichts über künftige Ergebnisse aus. Simulationen, Backtests und operative Demonstrationen sind Szenarien, keine Prognosen. Individuelle Ergebnisse weichen erheblich von den in Werbematerialien gezeigten ab.

Keine Anlageberatung

Nichts auf dieser Website stellt eine Empfehlung, ein Angebot oder eine Anlageberatung dar. Wir sind keine von der CVM zugelassenen Berater. Für eine individuelle Beratung wenden Sie sich an eine zertifizierte, registrierte Fachperson.

So verringern Sie Ihr Risiko

  • Beginnen Sie mit dem kleinstmöglichen Betrag und testen Sie eine Auszahlung, bevor Sie mehr einzahlen;
  • Aktivieren Sie die Zwei-Faktor-Authentifizierung schon beim ersten Zugriff;
  • Lassen Sie beim Broker kein Guthaben liegen, das über das genutzte hinausgeht;
  • Lesen Sie die Bonusbedingungen: Sie sperren oft Auszahlungen;
  • Misstrauen Sie jedem Versprechen einer garantierten Rendite oder eines Vermögensverwalters, der anbietet, für Sie zu handeln.
