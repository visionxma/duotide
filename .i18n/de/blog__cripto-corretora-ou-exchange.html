Krypto beim Broker oder auf einer Exchange: der Unterschied

Zwei Plattformen können denselben Bitcoin-Chart zeigen und dabei völlig unterschiedliche Dinge verkaufen. Die Frage, die beide trennt, ist kurz: Gibt es am Ende des Geschäfts eine Münze, die Ihnen gehört?

Exchange mit Verwahrung

Sie kaufen die Münze, und sie wird auf Ihrem Konto verbucht. Sie können sie auf eine Wallet übertragen, die nur Sie kontrollieren. Das Hauptrisiko ist, dass die Plattform zusammenbricht oder gehackt wird, während die Münze dort liegt — deshalb zieht, wer einen relevanten Betrag hält, das Geld meist auf eine eigene Wallet ab.

Differenzkontrakt (CFD)

Sie kaufen die Münze nicht: Sie schließen einen Vertrag ab, dessen Ergebnis der Preisentwicklung folgt. Eine Übertragung ist nicht möglich, weil es keine Münze gibt. Das ist kein Betrug — es ist ein anderes, verbreitetes und legitimes Produkt in vielen Märkten. Das Problem entsteht, wenn Marketingmaterial die Formulierung „Bitcoin kaufen" verwendet, um etwas zu beschreiben, das keinen einzigen Bitcoin liefert.

  • Gibt es eine Auszahlung in Krypto auf eine externe Wallet? Dann liegt vermutlich Verwahrung vor.
  • Fließt nur Fiat-Geld ein und aus? Dann handeln Sie einen Preis, kein Asset.
  • Erscheint „Hebel" auf dem Kaufbildschirm? Dann ist es ein Derivat, kein Kassakauf.

Prüfung bei Duotide

Duotide führt Kryptowährungen unter den verfügbaren Anlageklassen auf, aber die Art des Produkts muss im Vertrag bestätigt werden, nicht aus der Werbung abgeleitet. Fragen Sie den Support schriftlich, ob es eine Auszahlung in Krypto auf eine externe Wallet gibt. Die Antwort bestimmt, was Sie tatsächlich kaufen.

Häufige Fragen

Wenn ich beim Broker Krypto kaufe, gehört mir die Münze?

Das hängt vom Produkt ab. Bei einer Exchange mit Verwahrung gehört Ihnen die Münze, und sie kann auf eine eigene Wallet übertragen werden. Bei einem Differenzkontrakt (CFD) haben Sie eine Preisexponierung, keine Münze — es gibt nichts, was auf eine Wallet ausgezahlt werden könnte.

Kann ich auf eine eigene Wallet übertragen?

Nur, wenn die Plattform eine Auszahlung in Krypto anbietet. Ist die einzige Auszahlungsmöglichkeit in Real oder Dollar, ist das ein Zeichen dafür, dass Sie den Preis handeln, nicht das Asset selbst.
