อินดิเคเตอร์

RSI ดัชนีความแข็งแกร่งสัมพัทธ์ คำนวณอย่างไร

Naomi Tanakaตัวละครของกองบรรณาธิการ · ฝ่ายวิเคราะห์

สารบัญ

  1. สูตรของ RSI
  2. ตัวอย่างที่คำนวณด้วยมือ
  3. วิธีตีความระดับซื้อมากเกินไปและขายมากเกินไป
  4. ไดเวอร์เจนซ์: เมื่อราคาและ RSI ไม่ตรงกัน
  5. ข้อผิดพลาดที่พบบ่อยในการใช้ RSI
  6. RSI ในกรอบเวลาที่แตกต่างกัน
  7. วิธีใช้ RSI อย่างมีความรับผิดชอบมากขึ้น
กลับขึ้นด้านบน

RSI หรือดัชนีความแข็งแกร่งสัมพัทธ์ เป็นหนึ่งในอินดิเคเตอร์โมเมนตัมที่ใช้กันมากที่สุดในการวิเคราะห์ทางเทคนิค มันเปรียบเทียบความแข็งแกร่งของกำไรล่าสุดของสินทรัพย์กับความแข็งแกร่งของการขาดทุนล่าสุด ให้ผลลัพธ์เป็นตัวเลขระหว่าง 0 ถึง 100 ที่ช่วยระบุว่าเมื่อไรการเคลื่อนไหวอาจยืดตัวมากเกินไป

สูตรของ RSI

การคำนวณเริ่มจากค่าเฉลี่ยของกำไรและค่าเฉลี่ยของการขาดทุนตลอดจำนวนช่วงที่กำหนด โดยทั่วไปคือ 14 ช่วง จากค่าเฉลี่ยเหล่านี้ จะคำนวณความแข็งแกร่งสัมพัทธ์ ที่เรียกว่า RS:

RS = ค่าเฉลี่ยของกำไร / ค่าเฉลี่ยของการขาดทุน

จากนั้น RS จะถูกแปลงเป็นสเกล 0 ถึง 100 โดยใช้สูตร:

RSI = 100 - [100 / (1 + RS)]

ตัวอย่างที่คำนวณด้วยมือ

เพื่อให้การคำนวณง่ายขึ้น มาดูตัวอย่างที่มีการเปลี่ยนแปลงราคาเพียง 5 ครั้ง แทนที่จะเป็น 14 ครั้งตามปกติ เพียงเพื่ออธิบายการคำนวณ สมมติราคาปิดรายวันของหุ้นตัวหนึ่งดังนี้: R$ 10,00; R$ 10,20; R$ 10,15; R$ 10,40; R$ 10,30; R$ 10,50

การเปลี่ยนแปลงระหว่างราคาปิดแต่ละวันเป็นดังนี้:

  • วันที่ 2: +R$ 0,20 (กำไร)
  • วันที่ 3: -R$ 0,05 (ขาดทุน)
  • วันที่ 4: +R$ 0,25 (กำไร)
  • วันที่ 5: -R$ 0,10 (ขาดทุน)
  • วันที่ 6: +R$ 0,20 (กำไร)

ค่าเฉลี่ยของกำไร โดยรวมกำไรทั้งสามครั้งแล้วหารด้วย 5 การเปลี่ยนแปลง จะได้ (0,20 + 0,25 + 0,20) / 5 = 0,13 ค่าเฉลี่ยของการขาดทุน โดยรวมการขาดทุนทั้งสองครั้งแล้วหารด้วย 5 การเปลี่ยนแปลง จะได้ (0,05 + 0,10) / 5 = 0,03 ความแข็งแกร่งสัมพัทธ์คือ RS = 0,13 / 0,03 = 4,33 เมื่อใช้สูตรสุดท้าย: RSI = 100 - [100 / (1 + 4,33)] = 100 - 18,76 = 81,24

RSI ที่ใกล้ 81 บ่งชี้ว่ากำไรล่าสุดครอบงำการขาดทุนอย่างชัดเจนในช่วงเวลาที่ทำให้เรียบง่ายนี้ ทำให้อินดิเคเตอร์อยู่ในระดับที่อ่านได้ว่าซื้อมากเกินไป

วิธีตีความระดับซื้อมากเกินไปและขายมากเกินไป

การตีความแบบดั้งเดิมถือว่าค่าที่สูงกว่า 70 คือซื้อมากเกินไป บ่งชี้ว่าการเคลื่อนไหวขาขึ้นอาจยืดตัวมากเกินไป และค่าที่ต่ำกว่า 30 คือขายมากเกินไป บ่งชี้สิ่งเดียวกันสำหรับการเคลื่อนไหวขาลง ตัวเลขเหล่านี้ไม่ใช่สัญญาณซื้อหรือขายอัตโนมัติ ในแนวโน้มขาขึ้นที่แข็งแกร่ง RSI อาจอยู่เหนือ 70 เป็นเวลานาน และการขายทุกครั้งที่มันตัดผ่านระดับนี้อาจหมายถึงการออกจากแนวโน้มที่ยังมีพื้นที่ให้ไปต่อได้อีกมาก

ไดเวอร์เจนซ์: เมื่อราคาและ RSI ไม่ตรงกัน

ไดเวอร์เจนซ์เกิดขึ้นเมื่อราคาทำจุดสูงสุดใหม่ แต่ RSI ทำจุดสูงสุดที่ต่ำกว่าครั้งก่อน บ่งชี้ว่าการเคลื่อนไหวขาขึ้นกำลังสูญเสียแรงอยู่เบื้องหลัง แม้ราคาจะยังคงขึ้นต่อไปก็ตาม สิ่งเดียวกันนี้ใช้ได้กับด้านตรงข้าม โดยราคาทำจุดต่ำสุดที่ต่ำกว่าในขณะที่ RSI ทำจุดต่ำสุดที่สูงกว่า ไดเวอร์เจนซ์เป็นสัญญาณเตือนถึงความเป็นไปได้ที่การเคลื่อนไหวจะสูญเสียแรง ไม่ใช่การรับประกันว่าจะกลับตัวทันที

ข้อผิดพลาดที่พบบ่อยในการใช้ RSI

  • มองทุกจุดตัดที่ 70 หรือ 30 เป็นสัญญาณเข้าเทรดอัตโนมัติ โดยไม่คำนึงถึงบริบทของแนวโน้มใหญ่
  • ใช้ RSI เพียงลำพัง โดยไม่ตรวจสอบแนวรับ แนวต้าน หรือโครงสร้างโดยรวมของกราฟ
  • เปรียบเทียบ RSI ของสินทรัพย์ต่างชนิดกัน ราวกับว่าตัวเลขเดียวกันมีความหมายเหมือนกันในทุกบริบทความผันผวน
  • มองข้ามกรอบเวลา RSI ที่คำนวณบนกราฟ 5 นาทีวัดสิ่งที่ต่างไปมากจากอินดิเคเตอร์เดียวกันบนกราฟรายวัน

RSI ในกรอบเวลาที่แตกต่างกัน

สินทรัพย์เดียวกันอาจแสดงค่า RSI ที่แตกต่างกันมากขึ้นอยู่กับกราฟที่ใช้ RSI ที่คำนวณบนแท่งเทียน 5 นาทีตอบสนองต่อความผันผวนระยะสั้นมาก และอาจสลับไปมาระหว่างซื้อมากเกินไปกับขายมากเกินไปหลายครั้งภายในวันเดียว ในขณะที่ RSI ที่คำนวณบนแท่งเทียนรายวันหรือรายสัปดาห์มักเคลื่อนไหวช้ากว่าและมักสะท้อนการเคลื่อนไหวในระยะที่ยาวกว่า ก่อนที่จะเปรียบเทียบค่า RSI กับกฎตายตัว ควรยืนยันว่ากรอบเวลาที่เลือกเหมาะสมกับประเภทของการเทรดที่วางแผนไว้ ไม่ว่าจะเป็นเดย์เทรดที่รวดเร็วหรือการถือสถานะหลายวัน

วิธีใช้ RSI อย่างมีความรับผิดชอบมากขึ้น

RSI ทำงานได้ดีที่สุดในฐานะส่วนหนึ่งของการวิเคราะห์ที่กว้างขึ้น ไม่ใช่ตัวกระตุ้นการเข้าเทรดเพียงลำพัง การผสมผสานการอ่านค่า RSI กับแนวโน้มของกรอบเวลาใหญ่กว่า กับระดับแนวรับแนวต้าน และกับปฏิกิริยาของราคาใกล้ระดับเหล่านั้น มักให้การอ่านที่น่าเชื่อถือมากกว่าการใช้เพียงจุดตัดของตัวเลขคงที่ เช่นเดียวกับอินดิเคเตอร์ทางเทคนิคใด ๆ RSI อธิบายพฤติกรรมในอดีตของราคาและไม่ได้รับประกันว่าจะเกิดอะไรขึ้นต่อไป
