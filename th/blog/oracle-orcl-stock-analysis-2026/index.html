หุ้น Oracle (ORCL) ปี 2026: อะไรขับเคลื่อนราคา

ฝ่ายข่าวตลาดฝ่ายของ Duotide

สารบัญ

  1. สิ่งที่ Oracle ทำและรายได้มาจากไหน

กลับขึ้นด้านบน

Oracle เป็นที่รู้จักมานานหลายทศวรรษจากฐานข้อมูลและซอฟต์แวร์องค์กร แต่ในปี 2026 บริษัทถูกซื้อขายมากขึ้นเรื่อย ๆ ในฐานะชิ้นส่วนสำคัญของโครงสร้างพื้นฐานปัญญาประดิษฐ์ สัญญาคลาวด์มูลค่าหลายพันล้านอยู่ร่วมกันในงบดุลเดียวกันกับค่าใช้จ่ายหนักในดาต้าเซ็นเตอร์และหนี้สินที่เพิ่มขึ้น ความขัดแย้งนี้ช่วยอธิบายว่าทำไมหุ้นตัวนี้จึงดึงดูดความสนใจจากนักลงทุนและเทรดเดอร์มาก

บทความนี้รวบรวมตัวเลขและปัจจัยสำคัญที่ถูกอ้างถึงเกี่ยวกับ Oracle (ตัวย่อ ORCL จดทะเบียนใน NYSE) ด้วยข้อมูลจากเดือนมิถุนายน 2026 ตามที่เผยแพร่ต่อสาธารณะในขณะนั้น มูลค่าเปลี่ยนแปลงไปตามเวลา และไม่มีสิ่งใดในนี้ที่ควรอ่านเป็นคำแนะนำให้ซื้อหรือขาย วัตถุประสงค์คือการทำแผนที่สิ่งที่กำลังขับเคลื่อนหุ้นในขณะนั้น เพื่อช่วยเข้าใจประเภทของปัจจัยที่สมควรได้รับการติดตาม

สิ่งที่ Oracle ทำและรายได้มาจากไหน

Oracle จำหน่ายฐานข้อมูล แอปพลิเคชันองค์กร และโครงสร้างพื้นฐานคลาวด์ให้กับองค์กรขนาดใหญ่ ทั้งรัฐบาล ธนาคาร เครือข่ายสุขภาพ ผู้ให้บริการโทรคมนาคม และบริษัทในรายชื่อ Fortune 500 รายได้ส่วนใหญ่มาจากการสมัครสมาชิกระยะยาว ซึ่งทำให้บริษัทมีกระแสรายได้ที่คาดการณ์ได้มากกว่าโมเดลใบอนุญาตซอฟต์แวร์แบบเดิม

ในช่วงไม่กี่ปีที่ผ่านมา จุดสนใจของบริษัทเปลี่ยนไปสู่การประมวลผลบนคลาวด์ โดยเฉพาะแพลตฟอร์ม Oracle Cloud Infrastructure (OCI) ซึ่งเสนอพลังการประมวลผล พื้นที่จัดเก็บ และเครือข่าย รวมถึงบริการที่มุ่งเน้นเฉพาะสำหรับการฝึกฝนและรันโมเดลปัญญาประดิษฐ์ ในตลาดนี้ Oracle แข่งขันกับชื่ออย่าง Amazon Web Services, Microsoft Azure และ Google Cloud แต่อาศัยความได้เปรียบเฉพาะตัว คือฐานลูกค้าที่ใช้ฐานข้อมูลและแอปพลิเคชันของบริษัทมานานหลายปีแล้ว และสามารถย้ายภาระงานเหล่านั้นไปยังคลาวด์ของ Oracle เองได้อย่างค่อยเป็นค่อยไป

ตัวเลขที่อยู่ในเรดาร์เมื่อเดือนมิถุนายน 2026

ตามข้อมูลจาก Yahoo Finance เมื่อเดือนมิถุนายน 2026 Oracle มีมูลค่าตลาด 662,4 พันล้านดอลลาร์สหรัฐ โดยหุ้นซื้อขายที่ 230,33 ดอลลาร์สหรัฐและเพิ่มมูลค่า 18,4% ในปีนั้นจนถึงขณะนั้น อัตราส่วนราคาต่อกำไร (P/E) อยู่ที่ 41,4 ลดลงเป็น 28,6 ในประมาณการอนาคต (forward P/E) ซึ่งเป็นความแตกต่างที่บ่งชี้ว่าตลาดได้ตั้งราคาโดยคาดการเติบโตของกำไรที่มีนัยสำคัญในช่วงถัดไปแล้ว ช่วง 52 สัปดาห์อยู่ระหว่าง 134,57 ถึง 345,72 ดอลลาร์สหรัฐ และเงินปันผลที่จ่ายให้ผลตอบแทน 0,9% ต่อปี พร้อมกำไรต่อหุ้น (EPS) ที่ 5,57 ดอลลาร์สหรัฐ

ปัจจัยขับเคลื่อนการเติบโต: สัญญาคลาวด์ AI

ปัจจัยหลักที่ถูกอ้างถึงเพื่ออธิบายความสนใจในหุ้นตัวนี้คือความต้องการ Oracle Cloud Infrastructure สำหรับภาระงานปัญญาประดิษฐ์ บริษัทได้ปิดสัญญาระยะยาวและขนาดใหญ่กับชื่ออย่าง OpenAI, Meta และ xAI ซึ่งช่วยสร้างมูลค่าภาระผูกพันด้านผลงานคงค้าง (RPO) ที่ประมาณ 553 พันล้านดอลลาร์สหรัฐในไตรมาสที่สามของปีงบประมาณ 2026 ซึ่งเป็นการก้าวกระโดดประมาณ 325% เมื่อเทียบกับปีก่อนหน้า ตัวเลขนี้ทำหน้าที่เป็นตัวชี้วัดรายได้ตามสัญญาสำหรับปีต่อ ๆ ไป และสัญญาณใด ๆ ที่แสดงว่ามันยังคงเติบโตต่อไป หรือมีสัญญา AI และคลาวด์ใหม่ ๆ กำลังถูกปิด มักถูกตลาดจับตามองอย่างใกล้ชิด

อีกด้านของเหรียญ: ค่าใช้จ่ายและกระแสเงินสดติดลบ

การสร้างขีดความสามารถเพื่อรองรับปริมาณสัญญานี้ต้องอาศัยการลงทุนหนัก Oracle ใช้จ่ายหลายหมื่นล้านดอลลาร์ต่อปีในการสร้างดาต้าเซ็นเตอร์ใหม่ที่มุ่งเน้น AI ซึ่งทำให้กระแสเงินสดอิสระของบริษัทติดลบประมาณ 394 ล้านดอลลาร์สหรัฐ แม้จะมีฐานซอฟต์แวร์ที่ทำกำไรมาโดยตลอดในประวัติศาสตร์ก็ตาม รายได้รายปีของบริษัทประมาณ 57,4 พันล้านดอลลาร์สหรัฐ เติบโต 8,4% เมื่อเทียบปีต่อปี ซึ่งเป็นอัตราที่มั่นคง แต่ช้ากว่าการเติบโตของ backlog สัญญาคลาวด์เองมาก

นี่คือประเด็นหลักของการถกเถียงเกี่ยวกับหุ้นตัวนี้ หากตลาดมีความมั่นใจว่าการลงทุนหนักนี้จะให้ผลตอบแทนที่สมส่วนในปีต่อ ๆ ไป การเพิ่มมูลค่าก็มีแนวโน้มจะยั่งยืนหรือขยายตัวต่อ หากการใช้เงินสดยังคงสูงและเกิดข้อสงสัยเกี่ยวกับความสามารถในการชำระหนี้ที่เกี่ยวข้องกับการขยายตัวนี้ หุ้นก็มีแนวโน้มจะถูกกดดัน

ปัจจัยที่ต้องการความสนใจต่อเนื่อง

ในบรรดาจุดที่นักวิเคราะห์มักติดตามในขณะนั้น จากข้อมูลที่มีอยู่ ได้แก่ พัฒนาการรายไตรมาสของ backlog สัญญาคลาวด์ ความเร็วในการขยายขีดความสามารถของดาต้าเซ็นเตอร์เทียบกับความต้องการจริง ระดับการกระจุกตัวของรายได้ในลูกค้า AI รายใหญ่เพียงไม่กี่ราย และเส้นทางของหนี้สินที่กู้ยืมมาเพื่อสนับสนุนการขยายตัวนี้

ควรย้ำว่าตัวเลขที่นำเสนอในที่นี้สะท้อนสถานการณ์ที่เผยแพร่ในเดือนมิถุนายน 2026 ซึ่งเป็นช่วงเวลาที่บทความต้นฉบับถูกเผยแพร่ และอาจเปลี่ยนแปลงไปอย่างมากตั้งแต่นั้นมา บทความนี้มีวัตถุประสงค์เพื่อการศึกษา ไม่ถือเป็นคำแนะนำในการซื้อ ขาย หรือถือหุ้น และการตัดสินใจลงทุนใด ๆ ควรพิจารณาข้อมูลที่อัปเดต โปรไฟล์ความเสี่ยงของนักลงทุนแต่ละคน และข้อเท็จจริงที่ว่าการเทรดในตลาดหุ้นมีความเสี่ยงในการสูญเสียเงินทุนเสมอ
