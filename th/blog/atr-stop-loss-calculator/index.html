เครื่องคำนวณสต็อปลอสด้วย ATR: วิธีกำหนดระยะห่าง

ทีม Duotide · 24/09/2569 · อ่าน 4 นาที

หนึ่งในคำถามที่พบบ่อยที่สุดของผู้ที่เริ่มเทรดคือควรวางสต็อปลอสห่างเท่าไร วางใกล้เกินไปเพิ่มโอกาสถูกสต็อปจากความผันผวนปกติของสินทรัพย์ วางไกลเกินไปเพิ่มการขาดทุนเมื่อการเทรดผิดพลาด วิธีปฏิบัติในการตอบคำถามนี้คือใช้ ATR หรือ Average True Range เป็นข้อมูลอ้างอิงความผันผวนล่าสุดในการคำนวณระยะห่างของสต็อป

ATR วัดอะไร

ATR วัดขนาดเฉลี่ยของการเคลื่อนไหวราคาในจำนวนช่วงเวลาที่กำหนด โดยทั่วไป 14 ช่วง มันไม่บ่งบอกทิศทาง บอกเพียงว่าสินทรัพย์นั้นมักเคลื่อนไหวมากแค่ไหน สำหรับแต่ละแท่งเทียน จะคำนวณ True Range ซึ่งคือค่าที่มากที่สุดในสามตัวเลือกนี้ ผลต่างระหว่างจุดสูงสุดและต่ำสุดของแท่งเทียนปัจจุบัน ผลต่างระหว่างจุดสูงสุดปัจจุบันกับราคาปิดก่อนหน้า และผลต่างระหว่างจุดต่ำสุดปัจจุบันกับราคาปิดก่อนหน้า ATR คือค่าเฉลี่ยของค่าเหล่านี้ตลอดช่วงเวลาที่เลือก

สูตรของสต็อปที่อิง ATR

ระยะห่างของสต็อป = ATR x ตัวคูณ

สำหรับการเทรดฝั่งซื้อ: สต็อป = ราคาเข้า - ระยะห่างของสต็อป

สำหรับการเทรดฝั่งขาย: สต็อป = ราคาเข้า + ระยะห่างของสต็อป

ตัวอย่างที่แก้แล้วเป็นเงินบาท

สมมติการเทรดฝั่งซื้อในหุ้นตัวหนึ่งที่ซื้อขายที่ R$ 50,00 ด้วย ATR รายวัน R$ 1,20 และตัวคูณ 2 ระยะห่างของสต็อปจะอยู่ที่

  • ระยะห่าง = R$ 1,20 x 2 = R$ 2,40
  • สต็อป = R$ 50,00 - R$ 2,40 = R$ 47,60

ตอนนี้สมมติบัญชี R$ 20.000,00 พร้อมความเสี่ยงสูงสุด 1% ต่อการเทรด หรือ R$ 200,00 ขนาดสถานะคำนวณโดยหารความเสี่ยงเป็นเงินบาทด้วยระยะห่างของสต็อป

  • ขนาดสถานะ = R$ 200,00 / R$ 2,40 = ประมาณ 83 หุ้น

ด้วยสถานะนี้ หากราคาร่วงลงไปถึง R$ 47,60 การขาดทุนจะใกล้เคียงกับ R$ 200,00 ที่วางแผนไว้ ก่อนหักต้นทุนค่าคอมมิชชัน เป้าหมายอ้างอิงที่ 2R หรือสองเท่าของความเสี่ยงที่รับไว้ จะอยู่ที่ประมาณ R$ 54,80 แต่นี่เป็นเพียงข้อมูลอ้างอิงทางคณิตศาสตร์ ไม่ใช่การรับประกันว่าราคาจะไปถึงจุดนั้น

ATR ไม่ทดแทนโครงสร้างของกราฟ

ATR ตอบคำถามว่าสินทรัพย์นี้มักเคลื่อนไหวมากแค่ไหน มันไม่ตอบคำถามว่าไอเดียการเข้าเทรดของฉันผิดพลาดที่ไหน คำถามที่สองนี้มาจากการวิเคราะห์กราฟ เช่น จุดต่ำสุดก่อนหน้าหรือโซนแนวรับ ลำดับที่แนะนำคือ ก่อนอื่นทำเครื่องหมายระดับที่ทำให้การเทรดไม่มีความหมาย จากนั้นวัดระยะห่างระหว่างจุดเข้ากับระดับนั้น แล้วจึงเปรียบเทียบระยะห่างนี้กับ ATR เพื่อดูว่ามันสมเหตุสมผลเมื่อพิจารณาความผันผวนล่าสุดหรือไม่ หากระยะห่างเชิงโครงสร้างเล็กกว่าที่ ATR บ่งชี้มาก สต็อปอาจแคบเกินไปสำหรับสัญญาณรบกวนปกติของสินทรัพย์

ไม่มีตัวคูณที่สมบูรณ์แบบ

ตัวคูณต่ำสร้างสต็อปที่ใกล้กว่าและสถานะที่ใหญ่กว่าสำหรับความเสี่ยงเป็นเงินบาทเท่าเดิม แต่เปิดรับความผันผวนปกติมากกว่า ตัวคูณสูงสร้างสต็อปที่ไกลกว่าและสถานะที่เล็กกว่า ลดการถูกออกจากตลาดจากสัญญาณรบกวน แต่ต้องการให้ราคาเคลื่อนไหวมากกว่าจึงจะถึงผลลัพธ์เดียวกันในหน่วยทวีคูณความเสี่ยง ตัวคูณที่เหมาะสมขึ้นอยู่กับสินทรัพย์ กรอบเวลาที่เทรด และประเภทของ setup และควรทดสอบค่าต่าง ๆ กับข้อมูลย้อนหลังก่อนนำตัวเลขคงที่มาใช้กับทุกการเทรด

ระวังช่องว่างราคาและการเข้าเทรดจริง

การคำนวณนี้สมมติว่าสถานะจะถูกปิดที่ราคาสต็อปพอดี ในทางปฏิบัติ ช่องว่างราคา ข่าว และตลาดที่มีสภาพคล่องต่ำอาจทำให้การปิดสถานะเกิดขึ้นห่างจากราคาที่วางแผนไว้มาก โดยเฉพาะในสินทรัพย์ที่ปิดตลาดข้ามคืนหรือข้ามสุดสัปดาห์ ATR ช่วยกำหนดขนาดความเสี่ยงที่คาดไว้ในสภาวะปกติ แต่ไม่ได้ขจัดความเสี่ยงของการปิดสถานะที่แย่กว่าที่วางแผนไว้ในช่วงเวลาที่ตลาดตึงเครียด

ข้อควรจำสุดท้ายก่อนเทรด

กำหนดตัวคูณก่อนดูขนาดสถานะที่เป็นผลลัพธ์ ไม่ใช่ทางกลับกัน การเลือกตัวคูณเพียงเพื่อให้ได้ขนาดสถานะที่ดูสบายใจ กลับตรรกะของการบริหารความเสี่ยง สต็อปต่างหากที่ควรกำหนดขนาดสถานะ ไม่ใช่ขนาดที่ต้องการที่ควรกำหนดสต็อป
